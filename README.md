# 모바일 청첩장 클론 프로젝트

React와 TypeScript를 사용해 모바일 청첩장 화면을 구현한 학습용 클론 프로젝트입니다.

참고 자료의 구현 흐름을 따라가며 Figma 기반 레이아웃 설계, 모바일 UI 구성, 컴포넌트 분리, styled-components 기반 스타일링, Storybook을 활용한 UI 확인, Intersection Observer 기반 fade-in 효과를 학습했습니다.

## 프로젝트 목적

- React 기반 모바일 웹 UI 구현 경험 쌓기
- 청첩장 페이지를 기능 단위 컴포넌트로 분리하기
- styled-components를 활용한 스타일 구조화
- Storybook을 활용한 컴포넌트 단위 확인
- Intersection Observer를 활용한 스크롤 fade-in 효과 학습
- Figma로 레이아웃과 색상, 버튼 스타일을 먼저 정리한 뒤 구현하기

## 주요 기능

### 1. 메인 비주얼 영역

청첩장의 첫 화면에 들어가는 대표 이미지와 결혼 안내 문구를 구성했습니다.

### 2. 초대 문구 및 혼주 정보

신랑, 신부 및 혼주 정보를 별도 데이터로 분리하여 화면에 렌더링했습니다.

### 3. 예식 날짜 표시

결혼식 날짜를 한국어 형식으로 보여주고, 날짜 관련 유틸 함수를 분리했습니다.

### 4. 갤러리

여러 장의 이미지를 모바일 화면에 맞게 보여주는 갤러리 영역을 구현했습니다.

### 5. 지도 및 장소 안내

예식 장소 정보와 지도 이동 링크를 제공하는 영역을 구현했습니다.

### 6. 마음 전하실 곳

계좌 정보를 확인할 수 있는 영역을 구현했습니다.

### 7. 스크롤 fade-in 효과

Intersection Observer를 활용해 사용자가 스크롤할 때 각 섹션이 자연스럽게 나타나도록 구현했습니다.

<br />

## 디자인 / 설계 과정

구현 전에 Figma로 모바일 기준 레이아웃을 먼저 정리했습니다.

- 최대 너비 600px 기준 모바일 화면 설계
- 대표 이미지, 초대 문구, 갤러리, 지도, 계좌 정보 등 섹션 배치
- 버튼 상태별 스타일 정리
- 전체 컬러 팔레트 정리

이를 바탕으로 React 컴포넌트를 섹션 단위로 분리해 구현했습니다.

## 학습하며 고민한 점

### 컴포넌트 분리 기준

처음에는 화면을 기준으로 코드를 작성했지만, 이후에는 역할별로 컴포넌트를 나누는 방향으로 정리했습니다.
예를 들어 비주얼 영역, 초대 문구, 날짜, 갤러리, 지도, 계좌 정보처럼 청첩장의 각 섹션을 독립적인 단위로 분리했습니다.

### 데이터와 UI 분리

예식 정보, 혼주 정보, 장소 정보처럼 변경 가능성이 있는 값은 상수 파일로 분리했습니다.
이를 통해 UI 컴포넌트는 화면 표현에 집중하도록 구성했습니다.

### 스크롤 애니메이션 구현

스크롤 위치에 따라 섹션이 나타나는 효과를 구현하기 위해 Intersection Observer를 학습했습니다.
이를 커스텀 훅으로 분리하여 여러 섹션에서 재사용할 수 있도록 구성했습니다.

### AI 활용 방식

구현 중 모르는 개념이나 에러가 발생한 부분은 AI를 활용해 원인을 파악했습니다.
특히 TypeScript 타입 정의, styled-components 구조화, Intersection Observer 동작 방식 등을 질문하며 학습했습니다.

AI가 제안한 코드는 그대로 사용하지 않고, 프로젝트 구조에 맞게 수정하고 실행 결과를 확인한 뒤 반영했습니다.

## 회고

이 프로젝트를 통해 단순히 화면을 따라 만드는 것보다, UI를 어떤 단위로 나누고 어떤 데이터를 분리해야 유지보수하기 좋은지 고민할 수 있었습니다.
